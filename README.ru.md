# GH-Bridge — файловый мост Gaea ⇄ Houdini

[English](README.md) | **Русский**

Мост между **SideFX Houdini** и **QuadSpinner Gaea 2.0**, работающий через файлы на диске.
Он выгружает HeightField для Gaea, собирает проект Gaea (в GUI Gaea или прямо из Houdini
консольным сборщиком Gaea, не открывая её окно) и возвращает в Houdini рельеф после
эрозии и его маски.

```
Houdini                         диск                          Gaea 2.0
───────                         ────                          ────────
HeightField ── Export ──▶  input_height.exr  ──▶  File-нода ─▶ граф эрозии
                           manifest.json                          │ Сборка: F8 в GUI
                                                                  │ или Gaea.Swarm.exe
Terrain + Mask ◀─ Import ─ output/output_*.exr ◀── Export-ноды ◀──┘    из Houdini
```

## Возможности

- **Весь цикл из Houdini** — одна кнопка выгружает рельеф, собирает проект Gaea через
  `Gaea.Swarm.exe` в фоне и импортирует результат; окно Gaea не открывается. Сборка в GUI
  Gaea тоже поддерживается.
- **Рельеф и каждая маска — отдельными выходами** — выход 1 отдаёт рельеф после эрозии,
  выходы 2–4 — маски Gaea `flow`, `wear` и `sediment`, каждую как маску HeightField для
  входа Mask любой HF-ноды и каждую со своими настройками. Отсутствующие файлы
  пропускаются без ошибки.
- **Пропорции 1 в 1** — высоты пересчитываются под размер мира Gaea, поэтому рельеф
  выглядит одинаково в обеих программах и возвращается в Houdini в исходном масштабе.
- **Управление разрешением** — экспорт в полном разрешении HeightField или в 1/2, 1/3, 1/4.
- **Кэш по хэшу** — мост хэширует высоты входа, разрешение и набор слоёв. Если ничего не
  изменилось и выходы Gaea уже есть, сборка пропускается.
- **Манифест задачи** — `gh_bridge_manifest.json` описывает, что было выгружено, в каком
  разрешении и с какой кодировкой высот.
- **Безопасная очистка** — `cleanup_temp` никогда не удаляет файлы за пределами рабочей
  папки моста.
- **Только официальные точки входа Gaea** — мост работает через файлы на диске, GUI Gaea и
  документированный консольный сборщик `Gaea.Swarm.exe`. Лицензию и защиту он не трогает:
  всё, что ваша редакция Gaea разрешает или запрещает, действует как есть.

## Требования

- Houdini 19.5 или новее с Python 3 (разработано и проверено на 20.5; см.
  [Совместимость с версиями Houdini](#совместимость-с-версиями-houdini)).
- Gaea 2.0.
- Windows (пути по умолчанию рассчитаны на Windows, но меняются в конфиге или на ноде).

## Установка

### 1. Сделать модуль доступным для Houdini

Выберите один из вариантов.

**Вариант А — через `houdini.env`** (удобно, если планируете обновлять репозиторий).
Добавьте в `<Документы>/houdiniXX.X/houdini.env`:

```
PYTHONPATH = "C:/path/to/BridgeHGH;$PYTHONPATH"
```

**Вариант Б — копированием.** Положите `houdini_gaea_bridge.py` в
`<Документы>/houdiniXX.X/scripts/python/` (создайте папку, если её нет).

Перезапустите Houdini и проверьте в Python Shell:

```python
import houdini_gaea_bridge as ghb; print(ghb.__file__)
```

### 2. Собрать HDA

В Houdini откройте **Windows ▸ Python Shell** и выполните:

```python
exec(open(r"C:/path/to/BridgeHGH/build_gaea_bridge_hda.py").read())
```

В консоли появится `Installed HDA: ...\otls\gaea_erosion_bridge.hda`, а в сети SOP по
**Tab** — нода **Gaea Erosion Bridge**.

HDA устанавливается в пользовательскую папку `otls`. Чтобы удалить ассет, удалите оттуда
файл `gaea_erosion_bridge.hda`. После обновления репозитория запустите сборку ещё раз
(и перезагрузите модуль или перезапустите Houdini) — существующие ноды подхватят новую
версию.

## Использование

### В Houdini: экспорт

1. Соберите террейн, например `heightfield` ▸ `heightfield_noise`.
2. Создайте **Gaea Erosion Bridge** и подключите HeightField к его входу.
3. На вкладке **Paths** укажите **Bridge Dir** (по умолчанию `C:/Temp/gh_bridge`) и
   **Gaea Project** (`.terrain`; из него мост читает размер мира Gaea). Для кнопки
   **Open Project in Gaea** дополнительно задайте **Gaea Exe**.
4. На вкладке **Bridge** выберите **Export Resolution**: Full, 1/2, 1/3 или 1/4 от
   разрешения HeightField.
5. Нажмите **1. Export to Gaea**. В `Bridge Dir` появятся `input_height.exr`,
   `gh_bridge_manifest.json` и пустая папка `output/`.

   Слой `height` записывается как серый RGB EXR. Высоты пересчитываются под размер мира
   Gaea, чтобы пропорции рельефа совпадали 1 в 1 (см. [Масштаб высот](#масштаб-высот)).

### В Gaea: настройка проекта (один раз)

1. Откройте проект (вручную или кнопкой **Open Project in Gaea**).
2. Подключите `input_height.exr` через ноду **File** и соберите граф эрозии.
3. На каждый нужный выход повесьте ноду **Export**. В каждой: Format **EXR**, Location
   **Custom**, Output Path `<Bridge Dir>/output` (папка), If File Exists **Overwrite**,
   затем переименуйте ноду — в режиме Custom Gaea называет файл по имени ноды.
4. **Сохраните проект.** Чтобы собрать в GUI, нажмите **Build (F8)**; чтобы собирать из
   Houdini — см. следующий раздел.

| Выход Erosion2 | Имя Export-ноды | Слой в Houdini |
|----------------|-----------------|----------------|
| Out       | `output_height`   | `height`   |
| Flow      | `output_flow`     | `flow`     |
| Wear      | `output_wear`     | `wear`     |
| Deposits  | `output_sediment` | `sediment` |

Подключать все выходы не обязательно: мост импортирует то, что найдёт. Имена файлов
сравниваются без учёта регистра и пробелов по краям.

### В Houdini: сборка без открытия Gaea

Укажите на вкладке **Paths** **Gaea Project** и **Gaea Exe** и нажмите
**Export > Build > Import**. Нода выгрузит вход, запустит `Gaea.Swarm.exe` на сохранённом
проекте в фоне (Houdini не зависает, в Status идёт счётчик секунд) и по окончании
импортирует результат. Если вход и настройки не менялись с прошлой сборки, сборка
пропускается и импортируется уже готовый результат.

Шаги можно выполнять и по отдельности: **1. Export to Gaea**, **2. Build in Gaea**,
**3. Import Results**. **Cancel Build** останавливает идущую сборку.

Что важно знать:

- Swarm собирает проект **в сохранённом виде**. После правок графа сохраните проект в Gaea.
- Перед сборкой мост читает `.terrain` и не запускает её (с причиной в Status), если
  File-нода проекта не читает `<Bridge Dir>/input_height.exr` или Export-ноды не пишут EXR
  в `<Bridge Dir>/output`.
- Swarm сообщает об успехе, даже если ничего не собрал, поэтому мост судит о сборке по
  записанным файлам. Если их нет, Status об этом скажет; включите **Show Build Window**,
  чтобы увидеть сообщения самого Swarm.
- `Gaea.Swarm.exe` ищется рядом с **Gaea Exe**; если он лежит в другом месте, укажите
  **Gaea Swarm Exe**. Доступна ли сборка из командной строки, зависит от редакции Gaea.
- Без интерфейса Houdini (hython, скрипты) сборка выполняется синхронно.

### Шаблон эрозии: настройка эрозии Gaea из Houdini

Один раз сделайте проект Gaea **шаблоном**: `File` (вход моста) → ваш граф → нода
**Erosion2** → Export-ноды. Затем включите **Use Erosion Template** на вкладке **Erosion**.
Все параметры Erosion2 появятся в Houdini, прочитанные из проекта:

| Группа | Параметры |
|--------|-----------|
| General | Duration, Downcutting, Erosion Scale, Seed, No Erosion |
| Sediment Discharge | Suspended Load, Bed Load, Coarse Sediments (каждый со своим Discharge Angle), Deposition Boost |
| Shape | Shape, Shape Sharpness, Shape Detail Scale |
| Orographic Influence | Enable, Directional Precipitation, Direction, Rain Shadow, Reverse |

Меняйте их и жмите **Export > Build > Import** (или **2. Build in Gaea**): мост записывает
копию проекта `<Bridge Dir>/gaea_template_build.terrain` с вашими значениями и собирает её
через Swarm. Сам шаблон никогда не меняется, так что один шаблон годится для многих сцен
Houdini с разными настройками.

- Записываются только значения, отличающиеся от шаблона; всё остальное в проекте (другие
  ноды, незнакомые параметры) остаётся как есть.
- **Read from Project** заново читает значения из шаблона (это же происходит при первом
  включении режима); **Reset to Gaea Defaults** ставит значения Gaea по умолчанию.
- Если в проекте несколько нод Erosion2, укажите в **Erosion Node** имя той, что питает
  экспорты.
- Значения входят в кэш: изменение любого из них заставит следующий
  **Export > Build > Import** пересобрать; без изменений используется прошлая сборка.
- Диапазоны Slope и Altitude из Orographic Influence не выведены — они берутся из шаблона.
- С выключенным режимом Swarm собирает проект ровно как сохранён, а сборки в GUI Gaea (F8)
  значений из Houdini не видят.
- **Auto Build on Change** (под кнопкой Export > Build > Import на вкладке Erosion) сама
  запускает этот цикл, когда меняется любой параметр Erosion, как только вы перестали его
  менять (0.75 с, так что перетаскивание слайдера запускает одну сборку). С первого
  изменения и до импорта результата **все параметры ноды заблокированы**; доступна только
  **Cancel Build**, она же снимает блокировку. После переоткрытия сцены нода никогда не
  остаётся заблокированной.

### В Houdini: импорт

Нажмите **3. Import Results** (или это сделают **Build in Gaea** / **Auto Import**). С
этого момента результат выдаёт сама нода **Gaea Erosion Bridge** (никаких дополнительных
нод в вашей сети не создаётся), на четырёх выходах:

| Выход | Что в нём |
|-------|-----------|
| 1 · **Terrain** | HeightField из Gaea: `height` и `mask` (пустой или предпросмотр **Show Mask**). |
| 2 · **Flow** | Маска `flow` как слой `mask` на том же `height`. |
| 3 · **Wear** | Маска `wear`, та же раскладка. |
| 4 · **Sediment** | Маска `sediment`, та же раскладка. |

У выходов 2–4 стандартная раскладка HeightField, поэтому любой из них можно подключить во
вход **Mask** (второй вход) HF-нод — Noise, Erode, Distort и т. д. — или сначала
обработать отдельно (Blur, Mask by Feature…). При просмотре маска видна красным на
рельефе. Если файл маски не нашёлся, её выход будет пустым.

В поле **Status** — что нашлось. Рельеф возвращается в исходном размере и по высоте.
С галкой **Keep Input Resolution** (включена по умолчанию) каждый выход возвращается на
сетку входного HeightField через HeightField Layer (Replace), поэтому у него ровно то же
разрешение и размер вокселя, что у входа; если её выключить, останется разрешение сборки
Gaea.

Импорт только запоминает найденные файлы в ноде; все настройки на вкладке **Gaea Layers**
работают вживую, без повторного импорта. После новой сборки в GUI Gaea снова нажмите
**3. Import Results** — или включите **Auto Import (Gaea GUI builds)** и просто жмите F8
в Gaea. **Clear Import** возвращает ноду в режим «пропускать вход».

**Auto Import After Build** (включена по умолчанию) импортирует результат сразу после
окончания **2. Build in Gaea**; выключите, чтобы собирать, не трогая текущий результат.
**Export > Build > Import** импортирует всегда.

**Auto Import (Gaea GUI builds)** раз в секунду проверяет папку `output`. Когда Gaea записала новые файлы и
они 1.5 с не меняются (Gaea пишет их по очереди), нода импортирует их и пишет об этом в
Status. Нода помнит, что импортировала последним, поэтому со включённым Auto Import она
подхватит и сборку, сделанную, пока сцена была закрыта. Работает только в интерфейсе
Houdini (не в hython и не при batch-рендере) и не трогает ваш display flag. Пока идёт
**Build in Gaea**, Auto Import ждёт: эта сборка импортирует результат сама.

### Параметры ноды

**Вкладка Bridge**

| Параметр | Что делает |
|----------|------------|
| **Export Resolution** | Full / 1/2 / 1/3 / 1/4 от разрешения входного HeightField. Размер террейна не меняется, уменьшается только число пикселей (HeightField 500×500 на 1/2 выгрузится как 250×250). |
| **Export > Build > Import** | Весь цикл без открытия Gaea. |
| **1. Export to Gaea** / **2. Build in Gaea** / **3. Import Results** | Те же шаги по одному. |
| **Cancel Build** | Остановить идущую сборку Swarm. |
| **Open Project in Gaea** | Открывает GUI Gaea с проектом из **Paths**. |
| **Gaea Build Options** | **Build Resolution** (From Project, 512…16K; `--resolution` у Swarm), **Ignore Baked Cache** (`--ignorecache`), **Show Build Window** (консоль Swarm, для диагностики). |
| **Auto Import After Build** | Импортировать сразу после окончания **2. Build in Gaea** (по умолчанию включено). |
| **Auto Import (Gaea GUI builds)** | Импортировать автоматически, когда сборка в GUI Gaea записала новые файлы (см. выше). |
| **Clear Import** | Забыть импорт; нода пропускает свой вход. Заодно выключает Auto Import (Gaea GUI builds). |

**Вкладка Erosion**

| Параметр | Что делает |
|----------|------------|
| **Export > Build > Import**, **Status** | Та же кнопка и строка статуса, что на вкладке Bridge, — крутить параметры и пересобирать можно, не уходя с этой вкладки. |
| **Auto Build on Change** | Пересобирать автоматически при изменении параметра Erosion; нода заблокирована, пока результат не импортирован. |
| **Cancel Build** | Остановить сборку и разблокировать ноду. |
| **Use Erosion Template** | Собирать копию проекта со значениями Erosion2 ниже (см. [Шаблон эрозии](#шаблон-эрозии-настройка-эрозии-gaea-из-houdini)). Остальная вкладка видна только при включённой галке. |
| **Erosion Node** | Какой нодой Erosion2 управлять; пусто = единственной. |
| **Read from Project** / **Reset to Gaea Defaults** | Загрузить значения из шаблона / значения Gaea по умолчанию. |
| **General**, **Sediment Discharge**, **Shape**, **Orographic Influence** | Параметры Erosion2 с диапазонами Gaea. |

**Вкладка Gaea Layers**

| Параметр | Что делает |
|----------|------------|
| **Height** | *Gaea Result* — рельеф после эрозии. *Input HeightField* — оставить исходную высоту (на всех выходах) и взять из Gaea только маски. |
| **Keep Input Resolution** | Вернуть каждый выход на сетку входного HeightField (то же разрешение и размер вокселя, что у входа). Выключено — оставить разрешение сборки Gaea. |
| **Show Mask** | None / Flow / Wear / Sediment: показать эту маску красным на выходе Terrain (она кладётся в его `mask`). Верните None перед тем, как использовать выход Terrain дальше, иначе HF-ноды возьмут эту маску. |
| **Flow / Wear / Sediment** | По секции настроек на каждую маску, см. ниже. Все три всегда активны — каждая для своего выхода. |

В каждой секции маски:

| Настройка | Что делает |
|-----------|------------|
| **Normalize** | Разделить на максимум слоя, чтобы он занимал 0..1. Включено по умолчанию: Gaea пишет часть масок с крошечными значениями (`wear` до ~0.05), и без этого они выглядят пустыми. Исходные максимумы — в Status. |
| **Input Range** | Перенос Min/Max: всё, что ≤ Min, становится 0, всё, что ≥ Max, — 1. Поднимите Min, чтобы убрать слабые участки, опустите Max, чтобы усилить слабую маску. |
| **Gamma** | < 1 расширяет маску, > 1 сужает её к самым сильным участкам. |
| **Invert** | 1 − значение. |
| **Strength** | Итоговый множитель. |
| **Blur Radius** | Сгладить итоговую маску (единицы сцены, 0 = выкл.). |

Что означают маски (выходы Erosion2): **flow** — где течёт вода (тонкая сеть русел),
**wear** — где материал смыт, **sediment** — куда он отложился.

При конвертации HeightField в полигоны `mask` становится point-атрибутом.

**Вкладка Paths**

| Параметр | Что делает |
|----------|------------|
| **Bridge Dir** | Рабочая папка, общая с Gaea. |
| **Gaea Project**, **Gaea Exe** | Файл `.terrain` (его собирает Swarm, открывает GUI, из него берётся размер мира) и `Gaea.exe`. |
| **Gaea Swarm Exe** | Консольный сборщик Gaea. Пусто = `Gaea.Swarm.exe` рядом с Gaea Exe. |
| **Gaea Width / Height** | Размер мира Gaea в метрах. 0 = взять из проекта Gaea. |

Сам граф эрозии настраивается в GUI Gaea. Gaea собирает в разрешении из своего Terrain
Definition, если его не переопределяет **Build Resolution**; для быстрых превью уменьшите его.

### Масштаб высот

Gaea показывает значение пикселя `v` (0..1) как `v × Height` метров на террейне шириной
`Width` метров (Project ▸ Terrain Definition). Мост кодирует высоты Houdini так, чтобы
соотношение высоты и ширины в обеих программах было одинаковым:

```
span = ширина_houdini × gaea_height / gaea_width
v    = (h − min) / span        # экспорт
h    = v × span + min          # импорт
```

Размер мира Gaea берётся по порядку: параметры **Gaea Terrain Size** на ноде (если не 0)
→ файл `.terrain` из **Gaea Project** → 5000 × 2500 м. Кодировка сохраняется в манифест
(`height_encoding`), и **Import** по ней восстанавливает исходные высоты, так что рельеф
возвращается в масштабе Houdini. Если рельеф выше, чем позволяет Height в Gaea, в Status
появится предупреждение с минимальной высотой, которую нужно выставить.

Совет: эрозия в Gaea зависит от размера мира. Для физически корректного результата
выставьте ширину в Terrain Definition равной размеру террейна в Houdini — мост подстроится
сам.

### Кэш

При повторном **Export** мост сравнивает сигнатуру (хэш высот входа и их кодировки для
Gaea, разрешение экспорта, набор слоёв) с манифестом. Если всё совпадает и выходные файлы
на месте, ничего не перевыгружается, в Status будет сообщение, что пересборка не нужна, а
**Export > Build > Import** пропустит сборку. Любое изменение рельефа, разрешения или
размера мира Gaea сбрасывает кэш.

### Без HDA: шелф-инструменты

Модулем можно пользоваться и напрямую, например из шелфа:

```python
import houdini_gaea_bridge as ghb

ghb.run_from_selection()      # экспорт выделенной HeightField-ноды
# ... сборка в Gaea (F8) ...
ghb.import_from_selection()   # импорт результатов рядом с выделенной нодой
```

Без HDA импорт создаёт рядом с выделенной нодой небольшую цепочку нод `gaea_import_*`
(маски нормализованы, выбранный слой скопирован в `mask`) — без живых настроек ноды.

## Конфигурация

Значения по умолчанию можно задать без правки кода: положите `gh_bridge_config.json`
рядом с `houdini_gaea_bridge.py`. Все поля необязательны.

```json
{
  "bridge_dir": "C:/Temp/gh_bridge",
  "downsample": 2,
  "gaea_exe": "C:/Program Files/QuadSpinner/Gaea 2.0/Gaea.exe",
  "gaea_project": "D:/Projects/erosion.terrain",
  "gaea_swarm": "",
  "build_resolution": 0,
  "ignore_cache": false,
  "show_console": false,
  "gaea_width": 0,
  "gaea_height": 0,
  "output_maps": {
    "height": "output_height.exr",
    "flow": "output_flow.exr"
  }
}
```

`downsample`: 1 (полное), 2 (1/2), 3 (1/3) или 4 (1/4). `gaea_width`/`gaea_height`, равные
0, означают «взять из `gaea_project`». Пустой `gaea_swarm` — `Gaea.Swarm.exe` рядом с
`gaea_exe`; `build_resolution` 0 — разрешение из проекта.

Приоритет (от низшего к высшему): значения в коде → `gh_bridge_config.json` →
параметры ноды HDA.

## Совместимость с версиями Houdini

Мост разрабатывается на Houdini 20.5 и учитывает известные отличия 19.5:

| Отличие | Houdini 19.5 | Houdini 20.x | Как мост с этим справляется |
|---------|--------------|--------------|-----------------------------|
| `hou.Volume.voxelSize()` | нет | есть | Размер вокселя через `indexToPos()` (есть в обеих версиях), в крайнем случае по габариту |
| `hou.Volume.resolution()` | `hou.Vector3` из дробных | tuple из int | Приводится к int |
| Галка разрешения в HeightField Output | «Use Resolution» | внутри «Resolution» | Ищется по нескольким именам и по подписи |

Параметры нод Houdini ищутся по списку возможных имён. Каждый экспорт читается обратно и
проверяется: если другая версия запишет что-то неожиданное (например, постоянное
изображение, которое Gaea показывает как плоский террейн), в Status будет понятная ошибка.
При сборке HDA выводится заметка о каждом необязательном параметре, который не нашёлся.

Чтобы проверить версию Houdini, запустите в ней:

```powershell
& "C:\Program Files\Side Effects Software\Houdini XX.X.XXX\bin\hython.exe" tools/houdini_compat_check.py
```

или в Python Shell Houdini:

```python
exec(open(r"C:/path/to/BridgeHGH/tools/houdini_compat_check.py").read())
```

Скрипт перечисляет все типы нод, параметры и методы `hou.Volume`, которые использует мост,
делает пробный экспорт и импорт маски во временной папке и убирает за собой. Если что-то
отмечено как MISSING или FAIL, приложите отчёт к issue.

Тесты покрывают логику, не зависящую от `hou`: конфиг и его оверрайды, построение путей,

& "C:\Program Files\Side Effects Software\Houdini XX.X.XXX\bin\hython.exe" tests/test_bridge_logic.py -v

Ожидаемый результат: `Ran 58 tests ... OK`. Тесты также имитируют `hou.Volume` из

## Ограничения

- Структура графа Gaea меняется в GUI Gaea. Из Houdini можно менять значения Erosion2 в
  шаблоне, но не добавлять и не перекоммутировать ноды.
- Список параметров Erosion2 соответствует Gaea 2.3. Копии шаблона правятся как JSON;
  формат `.terrain` не является публичным API, поэтому будущая версия Gaea может потребовать
  обновления.
- Имена выходных файлов в нодах Export Gaea должны совпадать с ожидаемыми (см. таблицу
  или `output_maps` в конфиге).
- Вывод консоли Swarm нельзя перехватить (при перенаправлении вывода Swarm падает), поэтому
  его сообщения видны только в его собственном окне через **Show Build Window**.
